# Mon prochain jeu

Site de suggestions de jeux vidéo.

## Données

`data/jeux.json` : jeu de données de 168 jeux (genres, mécaniques, tags, studio, éditeur, série, plateformes, note critique, année), au même format que le catalogue du prototype, plus la liste `genres_voisins`. Liste écrite à la main, pas d'import IGDB ; les notes critiques sont approximatives. Voir `meta` dans le fichier.
